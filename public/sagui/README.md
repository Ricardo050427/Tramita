# Sagui

Personaje de Tramita: saguaro y guía. Todos los archivos son libres de fondo.

## Animados

| Estado | SVG animado | GIF | WebM con transparencia |
|---|---|---|---|
| Tranquilo (respira y parpadea) | sagui-reposo.svg | sagui-reposo.gif | sagui-reposo.webm |
| Saluda | sagui-saluda.svg | sagui-saluda.gif | sagui-saluda.webm |
| Piensa | sagui-piensa.svg | sagui-piensa.gif | sagui-piensa.webm |
| Te indica | sagui-indica.svg | sagui-indica.gif | sagui-indica.webm |
| ¡Listo! (salta de gusto) | sagui-feliz.svg | sagui-feliz.gif | sagui-feliz.webm |

- **SVG:** la animación va dentro del archivo, sin código extra. Se ve nítido a cualquier tamaño. Úsalo en páginas web con `<img src="sagui-saluda.svg">`.
- **GIF:** para presentaciones, Canva o WhatsApp. Mide 480 px de ancho.
- **WebM:** video con fondo transparente para editores de video y páginas web.
